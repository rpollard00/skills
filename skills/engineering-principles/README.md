# Engineering principles

These 23 skills are independent of Mako. Each keeps its own `SKILL.md` and license. They are explicit-only and can be deliberately read by any workflow.

Use [the trigger index](../engineering/mako/references/principles.md) to select an applicable principle, then read the full skill. The index is not a replacement for the instructions.

The imported principles retain their substance, with the agreed corrections for test sensitivity, scope, approval gates, compatibility obligations, and verification boundaries. See [selection decisions](../../docs/skill-router-decisions.md) and [provenance](../../docs/upstream-provenance.md).
